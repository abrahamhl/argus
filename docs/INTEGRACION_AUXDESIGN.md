8. Deploy + Certificado
9. **FIN**

**Tiempo añadido:** +1 día (audit + fixes)  
**Valor añadido:** +€700 facturado

### Checklist Pre-Launch ARGUS

**Antes de deploy, verificar:**
- [ ] HTTPS activo (SSL válido)
- [ ] HSTS configurado
- [ ] Content-Security-Policy básico
- [ ] X-Frame-Options: DENY
- [ ] X-Content-Type-Options: nosniff
- [ ] Referrer-Policy configurado
- [ ] SPF record DNS
- [ ] DMARC record DNS (mínimo p=none)
- [ ] CAA record DNS
- [ ] Cookies con Secure + HttpOnly
