## 1. Executive Summary

**ARGUS** is an autonomous **Evidence & Opportunity Control Plane**. Unlike traditional vulnerability scanners that generate speculative CVSS scores, fabricated alerts, or unactionable noise, ARGUS operates strictly on **cryptographically hashed, reproducible evidence**.

ARGUS is built specifically for **AUX Design** (`auxdesign.nl`) to deliver high-trust, non-invasive security assessments for Dutch small and medium-sized businesses (MKB).

```
Target
  ↓
Run
  ↓
Observation (Raw network telemetry)
  ↓
Evidence (Deep-frozen, SHA-256 hashed, immutable)
  ↓
Finding (Pure deterministic TypeScript rules — zero AI hallucination)
  ↓
Opportunity (Mapped to AUX Design service catalog with transparent EUR pricing)
  ↓
Remediation (Implementation playbooks for Dutch SMEs)
  ↓
Retest (Deterministic second inspection)
  ↓
Proof (Cryptographic before/after comparison: RESOLVED, IMPROVED, UNCHANGED)
```

## 2. Core Architectural Invariants

### 1. OFFLINE FIRST FOR SURE
- ARGUS runs **100% offline** by default or with synthetic company fixtures.
- When `ARGUS_OFFLINE_MODE=true`, network socket initiation is physically blocked at the collector layer.
- All report generation (HTML, JSON, Markdown), rules evaluation, opportunity mapping, and retest proofs execute locally with zero internet dependencies.

### 2. Zero Fear-Mongering Selling
- **Absolute ban on alarmism:** No "You are hacked", no fabricated CVSS scores, and no premature GDPR/AVG fine claims.
- Client-facing copy is written in clear, pragmatic Dutch (with English and Spanish translations).
- Positive security controls already in place are detected, celebrated, and highlighted alongside improvement opportunities.

### 3. Strict AI Sandboxing & Evidence Boundary
- AI models (LLMs) are **strictly excluded from the critical evidence and decision path**.
- The AI Analyst (`@argus/ai`) is an optional boundary adapter:
  - AI **cannot create evidence records**.
  - AI **cannot assign `VERIFIED` confidence** (strictly clamped to `INFERRED`).
  - Claims generated by AI lacking direct evidence links are **automatically dropped by the Policy Gate**.

### 4. Cryptographic Proof of Remediation
- Every evidence record is immutable (`Object.freeze`) and carries a canonical SHA-256 hash:  
  `sha256 = SHA-256(canonical(rawValue))`
- Bundles are cryptographically verifiable and can be digitally signed using **Ed25519** public-key signatures.
- Retesting produces a tamper-evident `Proof` linking baseline evidence to retest evidence.

## 4. Monorepo Architecture

The repository is structured as a clean `pnpm` monorepo:

```
argus/
├── apps/
│   ├── console/             # Operator CLI & TUI Control Plane
│   └── web/                 # Presentation PWA & offline viewer
├── packages/
│   ├── schema/              # Canonical TypeScript contracts & schemas
│   ├── collectors/          # Bounded network collectors & synthetic fixture harness
│   ├── core/                # Rules engine, ScopeGate, PolicyEngine, Retest, Reports, Crypto
│   └── ai/                  # Sandboxed AI analyst adapter & claim validator
├── docs/                    # Architectural specs, threat models, audits, and commercial backlogs
│   ├── THREAT_MODEL.md      # Detailed 14-vector threat model & security architecture
│   ├── SECURITY_AUDIT.md    # Comprehensive adversarial verification matrix & audit report
│   ├── ROI_BACKLOG.md       # Commercial Dutch SME playbook & Proof-as-a-Service model
│   └── SECURITY.md          # Vulnerability disclosure SLA & secure operational policy
└── .agent/                  # Persistent autonomous engineering state & decisions
```

### Package Responsibilities

| Package | Responsibility | Dependencies |
|---|---|---|
| **`@argus/schema`** | Pure type contracts: `Target`, `Run`, `Observation`, `Evidence`, `Finding`, `Opportunity`, `Remediation`, `Proof`, `ArgusBundle`. | Zero dependencies |
| **`@argus/collectors`** | Non-invasive collectors (DNS, TLS, HTTP headers, Email security, security.txt, metadata) with 1 MiB body limits, 10s timeouts, and synthetic offline fixtures. | Standard Node built-ins |
| **`@argus/core`** | Central PolicyEngine, ScopeGate, 11 deterministic posture rules, Ed25519 bundle signing, local persistence (`.argus_data/`), Dutch-first HTML/JSON/Markdown report generator, and Retest engine. | Minimal Node built-ins |
| **`@argus/ai`** | Boundary adapter for LLM analysis with Policy Gate enforcement, tool call validation, and evidence link verification. | `@argus/schema`, `@argus/core` |
| **`@argus/console`** | Interactive and scriptable CLI operator UX. | `@argus/core`, `@argus/collectors` |

## 5. Quickstart & The 60-Second Offline Demo

### Prerequisites
- Node.js >= 20.0.0
- `pnpm` >= 9.1.0 (strict dependency policy; `npm` is strictly prohibited)

### Installation & Build

```bash
# Clone the repository
git clone https://github.com/abrahamhl/argus.git
cd argus

# Install dependencies using pnpm exclusively
pnpm install

# Build all workspace packages
pnpm build

# Run the complete test suite (178 passing tests)
pnpm test
```

### The 60-Second Deterministic Demo

Run the end-to-end offline lifecycle demonstrating the complete control plane in action:

```bash
pnpm demo
```

**What the demo executes (100% offline):**
1. **Scope Gate:** Evaluates authorization policy for target `example-business.nl`.
2. **Observation & Evidence:** Collects synthetic baseline observations and computes SHA-256 immutable hashes.
3. **Deterministic Finding Engine:** Evaluates 11 security rules, identifying 7 posture gaps (missing HSTS, weak SPF, missing DMARC, missing CSP, etc.).
4. **Opportunity Engine:** Maps findings to actionable AUX Design services with hours and EUR estimates.
5. **Local Persistence & Reporting:** Saves run bundle and generates pre-rendered client (Dutch) and engineering HTML reports in `.argus_data/`.
6. **Simulated Remediation:** Applies standard engineering fixes to the target configuration.
7. **Retest Engine:** Collects post-remediation evidence, executes comparative analysis, and generates **7 cryptographic `RESOLVED` proofs**.

## 6. CLI Usage

The `@argus/console` CLI provides a comprehensive command set:

```bash
# Run the end-to-end offline demo
pnpm --filter @argus/console start demo

# Assess a target in offline/fixture mode
pnpm --filter @argus/console start assess example-business.nl --offline

# Inspect a previously saved run
pnpm --filter @argus/console start inspect <run-id>

# Retest a target against a baseline run
pnpm --filter @argus/console start retest example-business.nl <baseline-run-id> --offline

# Verify cryptographic evidence integrity and signatures in a bundle
pnpm --filter @argus/console start verify <path-to-bundle.argusbundle>

# Generate an Ed25519 signing keypair
pnpm --filter @argus/console start keygen

# Digitally sign an assessment bundle
pnpm --filter @argus/console start sign <bundle-path> <private-key-path>

# Export a sanitized client bundle (raw secrets stripped)
pnpm --filter @argus/console start export <run-id> <output-path>

# List all stored local assessment runs
pnpm --filter @argus/console start runs

# Generate and print client or engineering reports
pnpm --filter @argus/console start report <run-id> --client --lang nl
pnpm --filter @argus/console start report <run-id> --engineer

# Generate a commercial before/after case study
pnpm --filter @argus/console start case-study <baseline-run-id> <retest-run-id> --lang nl
```

## 7. Test Suite & Verification

The ARGUS monorepo contains a comprehensive automated test suite with **178 passing tests** covering core invariants, security threat vectors, collectors, report rendering, and persistence:

```bash
pnpm test
```

### Test Coverage Breakdown

- **`@argus/collectors` (8 tests):**
  - Offline mode socket blocking invariant.
  - Collector timeouts, headers extraction, 1 MiB body cap.
  - Synthetic baseline and remediated fixture integrity.
- **`@argus/core` (166 tests):**
  - **Adversarial Security Suite (`adversarial.test.ts`):** Validates all 14 vectors from `THREAT_MODEL.md` (SSRF, XSS escaping, CRLF injection, command injection, secret redaction, path traversal, Ed25519 signing, tamper detection).
  - **Core Invariants (`invariants.test.ts`):** Immutability (`Object.freeze`), hash determinism, finding-to-evidence linkage, opportunity mapping, retest before/after proof states.
  - **Scope Gate (`authorization.test.ts`):** Fail-closed authorization validation, expired scope rejection, wildcard subdomain matching.
  - **Policy Engine (`policy-engine.test.ts`):** IP validation (loopback, RFC 1918, cloud metadata `169.254.169.254`, IPv4-mapped IPv6, CGNAT).
  - **Confidence Model (`confidence.test.ts`):** 5-level confidence calculation and strict AI clamping.
  - **Rules & Catalog (`rules.test.ts`):** 11 deterministic posture rules, negative/positive checks.
  - **Persistence (`persistence.test.ts`):** Local storage, indexing, export, and path traversal rejection.
  - **Report Generator (`report-generator.test.ts`):** Dutch-first, English, Spanish HTML and engineering outputs.
  - **Retest Engine (`retest.test.ts`):** Comparison algorithms producing `RESOLVED`, `IMPROVED`, `UNCHANGED`, `REGRESSED`.
  - **Case Study (`case-study.test.ts`):** Markdown before/after proof case study generation.
- **`@argus/ai` (4 tests):**
  - Policy gate boundary enforcement, tool call validation, dropping ungrounded claims.

## 8. Security & Adversarial Review

ARGUS maintains a rigorous, continuous security posture:

- **[THREAT_MODEL.md](THREAT_MODEL.md):** Formal threat model detailing 14 attack vectors, architectural boundaries, and product threats vs. target vulnerabilities.
- **[docs/SECURITY_AUDIT.md](docs/SECURITY_AUDIT.md):** Complete adversarial verification report demonstrating automated test validation against all 14 threat vectors.
- **[SECURITY.md](SECURITY.md):** Vulnerability disclosure policy, 24-hour SLA, dependency management rules, and data handling commitments.

### Security Highlights
- **Zero Shell Execution:** Zero `child_process.exec` or shell invocation in the inspection pipeline.
- **SSRF Immunity:** Sockets to loopback, RFC 1918 subnets, cloud metadata IPs, and intermediate private redirects are unconditionally blocked.
- **XSS Immunity:** Mandatory `escapeHtml()` on all user/target strings across generated HTML reports; zero inline JavaScript or external CDNs required.
- **Secret Redaction:** Recursive scrubbing of sensitive headers (`Authorization`, `Cookie`, `Set-Cookie`, `X-API-Key`) across evidence logs and exported bundles.
