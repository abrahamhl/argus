# Security Policy

## Supported Versions
Currently, only the latest `main` branch of ARGUS is supported for security updates.

## Vulnerability Reporting Policy
Please do not report security vulnerabilities through public GitHub issues. Instead, please report them to the project maintainers privately.

## Responsible Disclosure
We ask that you provide us with a reasonable amount of time to resolve the issue before disclosing it to the public or a third party. We aim to acknowledge all reports within 48 hours and will work diligently to patch valid vulnerabilities.

## Network-Scope Warning
ARGUS is designed to collect data from target URLs. Ensure you have the explicit right and authorization to scan or inspect any target URL you submit to ARGUS. You are responsible for your own usage of this tool.

## No-Exploitation Policy
ARGUS must remain a passive collection tool. It will not attempt to exploit vulnerabilities, inject payloads, or mutate state on the target systems.
